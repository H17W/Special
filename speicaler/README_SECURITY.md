# Special Security — V17 FIXED17

## بعد اختراق البوت
1. لا تستخدم Bot Token القديم. أنشئ بوتًا جديدًا أو ولّد Token جديدًا من BotFather.
2. لا تضع BOT_TOKEN أو API_HASH أو جلسات Telegram داخل GitHub.
3. احذف أي جلسة Telegram قديمة كانت على جهاز أو Codespace غير موثوق وأنشئ جلسة جديدة.
4. أبقِ OWNER_ID/ADMIN_ID هو المعرّف الوحيد للمالك، وكل مستخدم آخر يمر عبر قائمة الصلاحيات.
5. النسخة تستخدم `drop_pending_updates=True` عند التشغيل حتى لا تنفذ تحديثات قديمة متراكمة.
6. إذا ظهر Token أو session في سجل أو ملف عام، اعتبره مكشوفًا وبدّله فورًا.

## مبدأ عزل الأوامر
أوامر الكتم وفك الكتم أصبحت وحدة مستقلة وتستخدم مطابقة دقيقة للأوامر. كتابة أمر آخر بالخطأ لا تغيّر حالة الكتم ولا تستولي على حالة انتظار أخرى.

## نطاق الكتم
- الخاص: جدول كتم عام للمستخدم.
- القروب/القناة: جدول كتم خاص بالمحادثة.
هذا يمنع حالة `تم الكتم` من أن تصبح غير قابلة للإلغاء بسبب اختلاف الجدول.
