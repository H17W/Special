# صلاحيات الميزات لكل مستخدم

تمت إضافة نظام مستقل لصلاحيات الميزات داخل لوحة المطور.

## الميزات التي يمكن السماح بها أو منعها

- User Automation
- إدارة الخاص
- التخزين والنسخ الاحتياطي
- الرسائل المهمة
- الإذاعة
- الحماية
- الإحصائيات
- الإعدادات

## طريقة الاستخدام

1. من 👑 إدارة المستخدمين اختر المستخدم.
2. اضغط 🛠️ صلاحيات الميزات.
3. كل زر يعرض حالة الميزة الحالية.
4. اضغط على الميزة لتبديلها بين ✅ مسموح و 🚫 ممنوع.
5. يمكن استخدام السماح بكل الميزات أو منع كل الميزات.

صلاحيات المستخدم محفوظة في SQLite في جدول `feature_permissions` ولا تعتمد على حالة واجهة البوت فقط.

> ملاحظة: يجب ربط هذه الصلاحيات بطبقة العزل الخاصة بكل مستخدم قبل السماح للمستخدمين الآخرين بتنفيذ عمليات على حسابات Telegram؛ حتى لا يتمكن مستخدم من الوصول إلى بيانات Workspace مستخدم آخر.
